# Keyrook's Homebrew tap

```sh
brew install keyrook/tap/passhold-cli
```

`passhold-cli` is the Passhold CLI: Passhold, the password manager by
Keyrook, in a terminal, for macOS and Linux. Each version installs the
program built for your system from the release on
https://github.com/keyrook/passhold/releases, checked by its SHA-256.

More: https://keyrook.com/cli/
